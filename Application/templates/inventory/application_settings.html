Configure Copilot provider

Create a Groq API key in the Groq console, add it to the application environment or deployment secret manager, then restart the web application. Free access is subject to Groq account eligibility and current usage/rate limits. Never paste a real key into chat or commit it to source control.

GROQ_API_KEY=<your-groq-api-key>
# Optional overrides:
COPILOT_LLM_API_URL=https://api.groq.com/openai/v1/chat/completions
COPILOT_LLM_MODEL=openai/gpt-oss-20b

Only the user's question is sent to Groq; no asset data is included. Obtain organizational approval before sending users' questions to an external provider.

Configure Intune sync

Store these values in the host environment or managed secret store. Grant Microsoft Graph application permission DeviceManagementManagedDevices.Read.All with administrator consent. Then restart the application environment and run the authorized sync command:

INTUNE_TENANT_ID=<tenant-id-or-domain>
INTUNE_CLIENT_ID=<application-client-id>
INTUNE_CLIENT_SECRET=<managed-secret>

python Application/manage.py sync_intune_devices \
  --confirm-read-only-authorized

Only exact unique serial references are matched to assets. Review duplicate and unmatched records on the Intune devices page when you have the required permission.
