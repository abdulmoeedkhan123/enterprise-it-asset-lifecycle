# IT Asset Lifecycle Management

This repository separates the **read-only ICT Business Analyst portfolio case study** from the **Django application** built from it.

| Folder | Contents |
|---|---|
| [`ICT Business analysis/`](<./ICT Business analysis/README.md>) | Fictional case study, requirements, process models, synthetic data, analyses, read-only dashboard prototype, UAT, and governance artifacts |
| [`Application/`](./Application/) | Django asset-management application, intended for authenticated operational workflows |

## Start here

- Browse the [ICT Business Analyst portfolio](<./ICT Business analysis/README.md>) for the fictional business case and its clearly labeled simulated outcomes.
- Read the [application setup notes](./Application/README.md) before running the separate Django application.

The portfolio dashboard is a read-only demonstration; it is not the management application. The application is a separate development project and must not be treated as production-ready or connected to real organizational data without the required security, privacy, operational, and vendor approvals.
